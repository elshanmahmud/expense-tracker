# expense-tracker

Personal expense tracking API app with user registration and JWT authentication

You have to create .env file and put an secret key with SECRET_KEY=YourSecretKey

Also you can use SQLite or PostgreSQL, by defualt app uses SQLite but you can add PostgreSQL key into .env file and if it is valid the program is gonna use PostgreSQL as an example "DATABASE_URL=postgresql://username:password@localhost:5432/db_name"
